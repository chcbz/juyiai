## 三分钟看懂 Demo

**新版状态：Web 1.16.135 本地验证候选，尚未部署。以下步骤对应新版；在线旧版在部署前仍可能显示“看分工／看流程”。**

1. 打开 [聚义](https://juyi.chcbz.net)，选择“免登录看示例”；也可打开 [Demo 入口](https://juyi.chcbz.net/demo)。
2. 在“办事”选择资料研究、内容生产或项目与代码协作模板，可修改需求后点击“开始办事”。
3. 在“选择承办人”核对候选好汉和整文示例报价，点击“确认由…承办”；这时才模拟预占费用，不自动开始真实任务。
4. 在议事中输入补充要求；回复为预置本地内容，不是模型生成。点击“查看示例成果”。
5. 核对成果清单后，可返回议事、显式“确认验收（模拟）”或取消示例事项。验收模拟结算，取消释放预占。可以重新体验，刷新也会重置。
6. 用“事项／资料／我的”查看当前演示状态与入口；真实账号、地图、上传和管理能力不在 Demo 内假装执行。

示例初始 100 文和候选报价都是演示数值，不代表活动赠送或线上单价。进入真实工作台仅带入模板，不迁移此页的修改、议事和模拟账目。

**此流程全部使用预置示例数据。** 无需登录，不触发真实模型执行、不保存为真实事项，不代表一次实际扣费或成果交付。真实使用需进入工作台并登录。

2026-11-12 访问时，`juyi.chcbz.net` 会重定向到 `kit.chaoyoufan.cn`；这是当次观察，不表示两个域名永远保持相同。页面仍可看到“聚义厅”旧称。若链接不可用，可从产品首页重新进入并反馈问题。

## 开始自己的第一个事项

建议先选一个范围小、验收标准清晰的任务，例如：

> 根据我提供的三份公开资料，整理一份方案对比简报。请列出每种方案的适用条件、风险和来源；输出一份可阅读的对比表。资料不足时先向我提问，不要编造来源。

### 1. 提出需求

说明目标、背景、输入资料、交付格式和完成标准。不要一开始就上传密码、密钥或未经授权的私人资料。

### 2. 选择承办人

结合候选 Agent 的能力、可用状态与报价选择承办人。推荐不等于已开始执行；显式确认承办才是业务流程中的授权入口。所需模型、技能、外部工具是否可用取决于 Agent 和部署环境。

### 3. 议事与执行

围绕同一事项补充上下文、查看回复和执行情况，必要时提出修改。普通“密议”和正式事项议事不是同一个流程，不要把一次普通对话当成已创建、已报价的事项。

### 4. 检查成果并验收

查看实际交付内容与对应版本，对照目标检查；需要调整时继续反馈。确认符合要求后验收；不再继续时通过合法取消入口处理。不要只凭“已经完成”的文字回复认定成果已交付。

## 费用与余额

- 用户侧统一以“文”展示余额与报价，换算口径为 **1 元人民币 = 100 文**；事项报价向上取整到整文。
- 事项报价是预估，不是已发生的模型成本。确认承办时预占费用；验收结算，取消释放预占。长期不验收不等于自动释放。
- 模型实际用量与费用按平台回执、已维护的单价等记录；估算 token 不等于真实消耗。工具自身费用是否可统计取决于具体接入能力。
- 余额和账单从工作台“个人中心”及对应钱包入口查看，以当前界面与服务端账本为准。
- 技能、Agent 托管等可能有独立费用或周期计费；操作前阅读当次页面说明。本指南不承诺固定赠送活动或长期价格。

业务细节见[文钱包合同](../specs/agent-economy-marketplace/beta-wen-billing.md)。合同和历史验收不能替代对当前线上账本的核对。

## 常见问题

**Demo 的成果是真的由模型现场生成的吗？** 不是。公开 Demo 明确标为本地模拟，便于了解交互，不用于证明模型效果。

**一定要登录吗？** 看公开介绍与 Demo 不需要。处理自己的事项需要登录，并满足当前站点的开放条件。

**开源是否意味着免费调用模型？** 不是。代码许可证与第三方服务费用是两回事；自行部署也需准备自己的配置与凭证。

**可以接入自己的 Agent 吗？** 项目包含 Runtime 与自行部署接入相关源码；请阅读 [Runtime 指南](../runtime/README.md)，按照目标环境完成接入，而不是复制别人的身份或生产状态。

**现在能一键自托管吗？** 尚不能把本仓视为经过干净环境验证的一键发行版。特别是 API 外部依赖与完整部署闭环仍需验证；见各组件的配置说明。

**截图与线上暂时不一样？** 截图来自新版本地候选，品牌为“聚义 JuyiAI”；线上仍可能保留旧版 Demo 和“聚义厅”文字。源码更新不等于已经部署，具体以实际发布为准。
