### 1. 业务规则不变

1. 每30天收费；主动离线、长期离线或永久失联均不暂停租期。有余额且原续费规则允许就自动续费，不依赖Runtime心跳或清理结果。
2. 自行部署资产属于接入方；解绑不要求本机在线，不发送清理命令，不删除本地资产。平台仍须结清自身事项/资金并撤销旧授权。
3. 不把旧用户自行部署的Runtime身份/私有状态交给新用户；新用户使用新的部署身份与Agent安装。不同用户共用的平台托管机器只有一个Runtime主服务，Agent身份/会话/目录/进程/凭据隔离。
4. 两种部署均由Runtime主动访问API，不要求固定IP、入站控制端口、常驻SSH隧道或新mTLS监听。
5. 平台托管保持原用户流程，技术接入由平台完成；不能要求用户手工导入主机JSON或生成第二密钥。
6. 原报价、预占、就绪捕获、退款、续费及收尾机制保留；不新增收费流程。租费/技能价格及退款规则唯一权威是[文钱包合同](../agent-economy-marketplace/beta-wen-billing.md)。

### 2. 最小技术边界

- **一个主服务，不是一个HTTP请求通道。** 复用已有主服务独占锁、按Agent生命周期串行门及进程内异步worker；worker不是第二个Runtime进程。
- **一个主机管理凭据，按Agent授权。** 主机只生成一次管理秘密，API只存散列；Agent授权由API精确到host/owner/Agent/原安装关系。管理凭据不进入Agent执行环境，不替代Agent安装凭据或session。
- **复用原逐授权单命令/单结果/ACK协议。** 不新建批量投递、容量协商、公平调度、主机连接世代或高可用接管协议。每次邀请不再生成SETUP/CONTROL两套秘密。
- **主机自动发现本机授权。** 原宿主worker管理器从认证API获取本机授权目录；每Agent原worker处理自身命令，新增Agent不手改主机文件，不额外配对。
- **不另建目标生命周期。** 保留现有setupId和安装关系；准备状态由实际库存/命令结果派生，付费及收尾状态由原binding/lease/intent决定。正式新邀请使用新授权ID，不加targetGeneration，也不删除原provisionGeneration/sessionGeneration。
- **不按表数优化。** 主机凭据与Agent授权必须分开；沿用已有setup、报价关联和投递存储。未证实需要前不合表、不批量改名、不以减少表数驱动资金模块迁移。

### 3. 正常流程

**托管：** 选择好汉/套餐→后台按现有配置自动分配主机、建立精确Agent授权→Runtime自动发现→准备实际目标与库存→原报价确认/预占→原安装与就绪核验→原首费捕获。用户不参与主机接入。

**自行部署：** 安装或复用主服务→本地生成主机秘密，导出无秘密登记材料→用户登录登记并在本机确认公开归属信息→Runtime主动读取本机授权目录。之后同机邀请其他Agent只走原报价/确认，不重复主机登记。

**失败/重试：** 原幂等键重查，GET无执行副作用；超时/未知不等于无副作用失败。只有原FAILED_NO_EFFECT→REFUNDED且未创建安装等安全条件满足，才允许新邀请；旧授权关闭，新授权ID与原失败记录分开。

### 4. 必须保留与明确不做

保留认证、精确授权、事务、资金幂等、持久回执、真实目标库存、已有沙箱、单写锁和必要恢复。这些各自对应越权、重复收费、重放或数据损坏风险，不是“复杂就删”。

不做：主机连接计费、连接世代、双主竞争/自动接管、克隆部署协调、每Agent双秘密、全主机批队列、新目标状态机、新通用消息框架、新钱包/续费调度、新容器平台、自动扩容、控制路由数据库或完整主机管理后台。

一台机器用不同状态根绕过独占锁，或复制同一主机秘密到另一台机器，属于部署身份错误；通过既有部署/配置检查和必要撤销修复，不承诺本期支持此类并行接管。主服务锁只证明同一受管状态根互斥，不声称全机器任意路径或跨机互斥。

### 5. 存量和完成边界

扈三娘的TRANSITION补登记仍独立于控制通道，李逵原租约记录保留。补登记不重新预占、enroll、adopt或追扣历史费用。本轮已核实扈三娘有安装但无租约，李逵已有租约和待办；自动续费开关未启用，不能称已完成。

业务实现只保留原路线和必要出站适配；切换前核对旧在途命令，禁止隐式网络fallback/双发。旧路由只作受控迁移，不扩成长期动态路由系统。

本次范围的源码/线上依据核查已收口，事实、实施缺口和上线条件见[审查](review.md)。既有RETAINED不是0文付费，需按原文钱包合同与正常续费发现区分，不能阻塞同用户正常租约。目标方案固定，不代表功能已实现或测试已通过；后续不得编码时自行选择替代协议或扩大范围。
